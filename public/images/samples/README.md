# Sample creatives (fictional brands only)

Everything in this folder must be work made for **invented, clearly fictional brands**.
No real brands, logos, packaging or third-party IP (movie/comic characters, sports
marks, celebrity likenesses). The site captions these as
"Sample work for fictional brands. Not client campaigns."

The files currently here are labelled placeholders. Replace each one with a real
sample at the same filename and size. PNG or JPG is fine; keep each file under ~400 KB
(export at quality 80–85). `next/image` handles resizing.
